01 ReAct 루프를 사용하여 견적 받기

사용자 질문 한 마디로 시작해 여러 도구 호출을 순차적으로 실행하는 에이전트 루프 구조

AGENT LOOP FLOW
사용자 입력 → 시스템 프롬프트 → 도구 호출 → 견적 산출 → 최종 응답
SEQUENTIAL TOOL CALLS
  • ① 사용자 입력 → 시스템 프롬프트 세팅
  • ② get_driver_details(owner) — 운전자 정보 조회
  • ③ get_vehicle_details(owner) — 차량 정보 조회
  • ④ calculate_risk(owner, cars) — 위험도 계산
  • ⑤ get_quote(owner, cars, risk) — 견적 산출
  • ⑥ 사용자에게 최종 응답
Key Insight
매 루프마다 도구 호출 결과가 컨텍스트에 쌓임 → 스텝이 늘수록 토큰 폭증 → 컨텍스트 윈도우 한계
02 메모리 구성 요소

단기/장기 메모리를 구분하여 컨텍스트 윈도우 한계를 극복하는 에이전트 메모리 아키텍처

SHORT-TERM MEMORY
  • 에이전트 상태 — 실행 계획, 루프 간 공유 데이터, 스크래치패드
  • 메시지 — 대화 기록, 메시지 순서
컨텍스트 윈도우 한계 존재
LONG-TERM MEMORY
  • 시맨틱 — 의미론적 컨텍스트 (벡터 DB)
  • 프로필 — 사용자 프로필 및 유사 데이터
  • 에피소드형 — 과거 상호작용 및 결과 (RL)
  • 프롬프트 — 시스템 프롬프트 (k-v 스토어)
외부 저장소 무제한
Key Insight
단기 메모리는 컨텍스트 윈도우 안에 들어가야 하므로 한계 존재 → 장기 메모리를 외부 저장소로 분리
03 Model Context Protocol (MCP)

에이전트와 데이터 소스 간 상호작용을 표준화하는 프로토콜

CONNECTION FLOW
사용자 → AI 에이전트
MCP Client → MCP Server
DB Driver → DB
EXPOSED TOOLS
  • get_owner_vehicles(ssn)
  • get_vehicle_by_vin(vin)
  • get_vehicle_telemetry(vin)
IMPLEMENTATION
  • Python 데코레이터 @mcp.tool()를 기존 함수에 붙이면 MCP 도구로 자동 등록
  • 어떤 DB든 동일한 인터페이스로 연결 가능 — 표준화가 핵심
Key Insight
기존 Python 코드에 @mcp.tool() 한 줄만 추가하면 에이전트가 호출 가능한 도구로 변환됨

05 데이터 소비자 주요 요소

데이터 상품의 신뢰, 보안, 성능을 위한 5가지 요소

5 KEY ELEMENTS FOR DATA CONSUMERS
  • ① 데이터 품질 — SageMaker Catalog 내 품질 및 계보(lineage) 액세스
  • ② 데이터 검색 가능성 — 메타데이터 및 비즈니스 용어집 기반 검색

  • ④ 보안 — Lake Formation FGAC(세분화된 액세스 제어)
  • ⑤ 저지연 액세스 — Glue Materialized View로 액세스 패턴 기반 사전 계산
SageMaker Catalog Trusted Identity Propagation Lake Formation FGAC Glue Materialized View
