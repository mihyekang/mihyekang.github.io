AWS Transform이란?

"어떤 도구든, 어떤 에이전트든, 단 하나의 플랫폼에서"

AWS Transform은 레거시 시스템의 분석부터 코드 변환까지를 단일 플랫폼에서 처리하는 에이전틱 AI 서비스다. 기존에는 마이그레이션 작업에 수개월이 걸리고, 전문 인력이 많이 필요했다. Transform은 이 과정을 AI 에이전트가 자동으로 처리하도록 한다.

CLI

IDE

에디터를 벗어나지 않고 변환 작업, 모니터링, 결과 확인까지 처리

🤖
코딩 에이전트

Kiro 등 다른 에이전트와 Transform 에이전트가 상호작용

Transform → Kiro → Amazon Q 파이프라인

세션의 핵심 메시지 중 하나는 Transform 이후의 흐름이었다. AWS Transform 혼자 모든 걸 해결하지 않는다. 이후 단계가 중요하다.

AI 기반으로 전환

AWS Transform이 레거시 코드를 변환한 뒤, 부분 변환(Partially Transformed) 영역은 Kiro가 이어받아 UI 현대화, 자동화된 테스트, AWS 배포까지 마무리한다. Amazon Q는 그 위에서 데이터와 업무 방식을 AI 중심으로 통합하는 역할이다.

세션 핵심 정리

📌 핵심 메시지 5가지

  • 레거시 시스템 현대화는 더 이상 미룰 수 없는 과제다
  • 에이전틱 AI가 마이그레이션·현대화 속도를 근본적으로 변화시킨다
  • AWS Transform은 풀스택 분석~변환을 단일 플랫폼에서 수행한다
  • Transform이 남긴 비즈니스 컨텍스트는 Kiro의 Spec-driven 방식으로 마무리된다
  • Amazon Q는 통합된 데이터 위에서 일하는 방식 자체를 AI 기반으로 전환한다
