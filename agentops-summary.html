03 관측성의 변화

04 에이전틱 루프에서의 관측성
Memory
  • 이것은 사용자의 메모리입니까?
  • 에이전트가 올바른 컨텍스트에 접근하고 있습니까?
Tools
  • 에이전트가 이 도구에 접근할 수 있습니까?
  • 적절한 매개변수로 도구를 호출할 수 있습니까?
Actions
  • 이 행동이 허용되나요?
  • 이 행동이 실패했을 때 대체안이 있나요?
User
  • 이 사용자는 누구인가요?
  • 이 사용자는 에이전트를 호출할 권한이 있나요?
Observation 핵심 질문: 관측 결과가 목표와 일치합니까? 가드레일이 적용되었습니까? 인간의 감독이 필요합니까?

09 PoC부터 프로덕션까지
POC 단계
  • AI Agent: 성공 지표 정의, 에이전트 개발
  • Evaluations: 베이스라인 수립, 검증
  • Runtime/Observability: 배포 + 모니터링
프로덕션 배포 후 (매 업데이트)
오프라인 평가 → 쉐도우 모드 → A/B 테스트 → 전체 Rollout
지속적 모니터링 / 평가 / 최적화 (Observability + Evaluations + Optimization)
POC는 "동작하는가?"를 증명하는 것이고,
프로덕션은 "안전하게, 지속적으로, 측정 가능하게" 운영하는 것입니다.
