AI 에이전트를 만들기는 쉬운데, 제대로 동작하는지 어떻게 알 수 있을까?
이 세션은 그 질문에 답하는 내용이었다. AgentCore Evaluations를 중심으로 개발-운영 전 주기에서 에이전트 품질을 높이는 방법을 설명했다.

왜 에이전트 평가가 어려운가?

⚠️ 평가 프로세스 전체가 몇 달이 걸릴 수 있으며, 새 모델·새 에이전트 버전·새 프롬프트마다 전 과정을 반복해야 한다.

기존 에이전트 평가 사이클은 이런 단계를 반복한다:

1
에이전트 구축
2
데이터셋 찾기 및 생성
3
Evaluator 선택
4
에이전트를 평가할 모델 선택
5
평가 수행 인프라 구축
6
결과 기록 및 인사이트 종합·조정
7
프로덕션 환경에서 모니터링

AgentCore Evaluations 소개

"실제 성능을 기반으로 에이전트 품질을 향상시킨다"

AWS가 공개한 AgentCore Evaluations는 세 가지를 제공한다:

기능설명
실시간 품질 인텔리전스 13개의 기본 제공 평가자로 실시간 인터랙션 샘플링 및 평가. 실제 사용자 행동 기반 인사이트 제공
맞춤형 비즈니스 스코어링 사용자 정의 평가자로 특정 유스케이스에 맞게 구축. 전체 궤적·최종 응답·개별 단계 세분화 지원
인프라 오버헤드 없음 Amazon CloudWatch 로그에서 즉시 평가 가능. 인프라 구축에 필요한 수개월 노력을 절감

평가 방식: 온디맨드 vs 온라인

온디맨드 품질 보증 (QA)
  • 타겟 테스팅: 단계별 디버그
  • 구성 요소 검증, CI/CD 통합
  • 벤치마크 테스트: 안정성 검증
  • 배포 전 확인
온라인 지속적 모니터링
  • 프로덕션 세션 연속 샘플링
  • 대화 품질 실시간 측정
  • 라이브 대시보드 모니터링
  • 구성 요소별 지표 추적

사용자 시뮬레이터 (Preview)

평가 데이터셋이 없거나 실제 사용 데이터가 없는 상황에서도 평가할 수 있다. Amazon Bedrock FM 기반 사용자 시뮬레이터가 가상의 사용자처럼 에이전트와 대화한다.

시뮬레이터에 설정할 수 있는 것들:

  • Context: 사용자의 상황·배경
  • Goal: 대화의 목적
  • 사용자 특성: 전문성, 대화 스타일, 인내심 등

덕분에 고정 스크립트 없이 실제 사용자 행동을 현실적으로 재현하고, 엣지 케이스를 발견할 수 있다.

코드 기반 Evaluator (New!)

"완전한 결정론적 방식. LLM 비용 없음. 맞춤형 평가 로직 직접 적용 가능"

비결정적: 같은 입력에 다른 점수 가능결정론적: 같은 입력, 항상 같은 점수

정규식·소수점 정밀도 검증 불가정확한 수치 검증 가능 (e.g. 소수점 5자리)

📌 세션 핵심 요약

  • 에이전트 평가는 기존에 수개월이 걸리는 고비용 작업이었다
  • AgentCore Evaluations는 인프라 없이 CloudWatch 로그에서 즉시 평가를 가능하게 한다
  • 사용자 시뮬레이터로 평가 데이터 없이도 에이전트 테스트가 가능해졌다
  • 코드 기반 Evaluator는 LLM 없이 결정론적 평가를 제공한다
  • Production Failures → Fix → Gate의 플라이휠 구조로 지속적 품질 개선이 가능하다
